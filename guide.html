📍 0. 내 활동 동네(동 이름) 및 기준 지역 설정 (시작 전 필수!)

중개노트를 처음 시작하셨다면 대표님의 중개사무소가 위치한 지역이나 주로 활동하는 동네(예: 연남동, 망원동, 성수동 등)를 가장 먼저 등록해 주세요!
한 번만 등록해 두시면 매물 등록 시 동 이름을 매번 직접 칠 필요 없이 칩 버튼으로 1초 만에 선택할 수 있으며, 상단에서 동별 원터치 필터링이 가능합니다.

1단계: 화면 우측 상단 [⚙️ 설정] 터치
화면 오른쪽 위의 [⚙️ 설정] 버튼을 누르면 환경 설정 창이 열립니다.
2단계: [📍 내 활동 동 목록]에서 내 동네 등록 및 불필요한 동 삭제
• 동 추가: [새로운 동 이름] 입력란에 대표님이 일하시는 동(예: 연남동)을 입력하고 파란색 [추가] 버튼을 누릅니다.
• 동 삭제: 사용하지 않는 동 이름 옆의 빨간색 [✕]를 누르면 깔끔하게 삭제됩니다. (동 칩을 삭제해도 해당 동에 등록된 매물 원본 데이터는 절대 지워지지 않습니다)
3단계: [기본 시/구] 설정 (네이버 지도 1초 연동)
• 기준 지역 입력: [기본 시/구 (네이버 지도 검색용)] 입력란에 서울특별시 마포구, 경기도 성남시 분당구처럼 사무소 관할 시/구를 입력하세요.
• 매물 카드에서 지번 주소나 건물명을 누르면 이 기준 지역과 결합되어 네이버 지도에서 정확한 위치로 즉시 연결됩니다.
💡 실무 팁: 활동 동이 하나도 등록되어 있지 않으면 메인 화면에 [📍 활동 지역(동)을 먼저 설정해 주세요] 안내가 나타나며 [새 매물] 등록 시에도 설정 창으로 친절히 안내합니다.
🛒 1. 손님 장바구니 쇼잉 (특허급 현장 브리핑 솔루션)

"공인중개사는 한 번에 손님 1팀을 모시고 여러 집을 투어합니다."
기존 앱들처럼 집마다 일일이 들어가 약속을 개별 등록할 필요가 없습니다. 쇼핑몰 장바구니에 상품을 담듯, 손님 1팀을 선택해 두고 전체 매물에서 보여줄 집을 톡톡 담아 바로 현장 투어를 진행하세요!

1단계: [👤➕ 손님 등록] 터치하여 손님 생성
상단 드롭다운 옆의 [👤➕ 손님 등록]을 누르고 방문 날짜, 약속 시간, 손님 전화번호(뒷4자리 또는 전체 번호), 손님 구분(직방/네이버/신혼부부 등 태그), 희망조건 메모를 입력 후 저장합니다.
저장 즉시 상단에 파란색 [🛒 5678 손님 장바구니] 배너가 켜지며 쇼잉 준비가 완료됩니다.
2단계: 전체 매물을 둘러보며 [🛒 담기] 버튼 톡톡 누르기
장부의 매물을 편안하게 둘러보세요. 모든 호수(예: 201호, 302호) 옆에 입체적인 [🛒 5678에 담기] 버튼이 표시됩니다.
보여줄 집마다 버튼을 누르면 파란색 [✔️ 담김]으로 바뀌며 손님 장바구니에 즉시 묶입니다. (다시 누르면 손쉽게 빠집니다)
3단계: [📋 담긴집만] 눌러 현장 출발 & 인라인 피드백 작성
손님과 동행할 때는 상단 배너의 [📋 담긴집만]을 누르세요. 다른 집들은 숨겨지고 오늘 보여주기로 한 집들만 딱 정렬되어 현장 동선이 한눈에 파악됩니다.
집을 보고 나온 직후 각 호수 카드의 [💬 현장 반응/메모] 입력란에 손님 반응(예: "채광 우수, 보증금 500 조율 시 즉시 계약 의사")을 바로 적어두세요. 자동 저장됩니다.
4단계: 투어 완료 시 [🏁 완료·보관] 누르기 (영구 기록 보존)
손님 배웅 후 배너의 [🏁 완료·보관]을 누르면 현재 장바구니에서 정리되며, 손님 정보와 보여준 집 목록, 현장 메모가 상단 [🗂️ 지난 손님] 보관함으로 자동 저장됩니다.
💡 장바구니 배너 하단 4개 버튼 상세 기능
• [ ➕ 매물담기 ] / [ 📋 담긴집만 ] : 전체 매물을 보며 담는 모드와 담아둔 집만 집중 브리핑하는 모드를 1초 만에 상호 전환합니다.
• [ 🏁 완료·보관 ] : 손님 투어가 끝났을 때 상단 [🗂️ 지난 손님] 보관함으로 이동시킵니다. (며칠 뒤 재방문 시 언제든 원클릭으로 다시 살리기 가능)
• [ ✕ 닫기 ] : 손님 장바구니를 파기하지 않고 잠시 닫은 뒤 평소의 전체 매물 화면으로 복귀합니다. (상단 드롭다운에서 언제든 다시 선택 가능)
• [ 🗑️ 삭제 ] : 취소되었거나 잘못 등록한 손님 장바구니를 영구 삭제합니다. (매물 원본은 100% 안전하게 유지)
🗂️ 상단 [지난 손님] 보관함 200% 활용법
화면 오른쪽 상단의 [🗂️ 지난 손님] 버튼을 누르면 이전에 안내했던 모든 손님의 날짜, 전화번호, 보여준 매물 리스트, 손님 반응 메모가 일목요연하게 표시됩니다.
손님이 다시 찾아오셨을 때 [🔄 다시 손님 목록으로 살리기]를 누르면 이전 담긴 매물 그대로 장바구니가 즉시 활성화됩니다!
➕ 2. 주소지 & 도어락 비밀번호 등록하기 (아파트 / 빌라)
1단계: 상단 [➕ 새 매물] 터치 및 동 선택
화면 우측 상단 파란색 [➕ 새 매물] 버튼을 누르면 등록창이 열립니다. 상단 동 칩에서 해당 매물의 동을 원터치로 선택합니다.
2단계: 지번, 건물명, 건물 동(아파트) 입력
• 지번: 234-12 번지수를 입력합니다.
• 건물/단지명 (선택): 성산시영, 고건빌라 등을 적어두면 목록에서 알아보기 쉽습니다.
• 건물 동: 대단지 아파트는 101동처럼 동을 적어주시고, 일반 빌라/다가구는 비워두세요! (비워두면 건물 단위로 카드가 깔끔하게 묶입니다)
3단계: 호수 및 비밀번호 스마트 입력
• 호수: 201호 등을 입력합니다.
• 공동현관 비번 vs 세대 도어락 비번: 건물에 처음 호수를 등록할 때는 공동현관 비번과 세대 도어락 비번을 모두 입력할 수 있습니다. 이미 등록된 건물에 호수를 추가할 때는 공동현관 비번이 상단에 자동으로 안내되고 세대 도어락 비번만 집중 입력하도록 화면이 스마트하게 자동 최적화됩니다.
4단계: 연락처 및 특이사항 메모
• 임대인 정보: 비번 확인처 및 임대인 연락처
• 세입자(거주자) 정보: 방문 전 통화할 세입자 호칭과 연락처
• 💡 물건지 특이사항 메모: 주차 규정, 애완동물 여부, 방문 선호 시간 등을 자유롭게 적어두면 현장 카드에 노란 강조 박스로 눈에 띄게 표시됩니다.
• 약속 바로잡기 (선택): 지금 바로 잡힌 쇼잉 약속이 있다면 하단에서 날짜, 시간, 손님을 한 번에 등록할 수 있습니다.
⚡ 실무 3초 완성 꿀팁: 이미 등록된 건물에 새로운 호수가 나왔을 땐 상단 [새 매물]을 누르지 마시고, 해당 건물 카드의 [➕ 호수 추가] 버튼을 누르세요. 동, 지번, 건물명, 공동비번이 100% 자동 채워져 호수와 세대 비번만 적고 바로 끝납니다!
🔍 3. 현장 1초 즉시 검색 & 바로등록 연동
1단계: 지번, 동·호수, 건물명, 세입자 초고속 검색
상단 검색창에 '101동', '302호', '성산', '234-12', '010-1234' 등 단어 하나만 입력해도 0.001초 만에 해당 매물 카드가 눈앞에 즉시 정렬됩니다.
검색어 입력 시 우측에 나타나는 동그란 [✕] 버튼을 누르면 검색어가 즉시 지워집니다.
2단계: 검색 결과가 없을 때 [새 매물 바로 등록] 버튼 제공
검색창에 입력한 주소나 건물명이 등록되어 있지 않다면, 빈 화면 대신 [➕ '입력한 검색어' 새 매물 바로 등록] 버튼이 시원하게 나타납니다.
버튼을 누르면 검색창에 쳤던 단어가 지번이나 건물명에 자동으로 입력된 채로 등록창이 열려 오타 없이 즉시 매물을 생성할 수 있습니다.
📦 4. 매물 보관(숨기기) vs 완전 삭제 & 보관 한도 관리
🔹 계약 완료된 집은 [📦 보관하기 (목록에서 숨김)] - 적극 권장!
계약이 완료된 집은 절대로 완전 삭제하지 마시고 [상세 정보 펼치기] ➔ [📦 보관/삭제] ➔ [📦 보관하기]를 누르세요.
메인 목록에서는 깔끔하게 숨겨져 화면이 쾌적해지고, 소중한 도어락 비밀번호와 임대인 연락처는 안전하게 보존되어 2년 뒤 재계약이나 다음 매물 출회 시 1초 만에 살릴 수 있습니다.
🔹 보관된 매물 확인 및 되살리기 [📦 보관·숨김 필터]
상단 동 필터 칩 맨 오른쪽에 나타나는 [📦 보관·숨김 (N개)] 칩을 누르면 보관 처리해 둔 매물들만 모아볼 수 있습니다.
다시 거래 가능한 상태가 되면 해당 호수의 [♻️ 메인으로 살리기] 버튼을 누르면 즉시 원래 동 목록으로 원상복구됩니다.
🔹 완전 삭제 (영구 제거)
잘못 등록했거나 완전히 파기해야 할 매물은 [🗑️ 완전 삭제]를 선택합니다. 도어락 비번 및 모든 기록이 복구 불가능하게 영구 제거됩니다.
👑 무료 플랜 보관 한도 (100개) 안내
중개노트 개인 무료 에디션은 최대 100개의 활성 매물까지 등록·보관하실 수 있습니다. 카운트 바에 실시간 수량이 표시되며, 한도에 도달하면 계약 완료된 매물을 [📦 보관하기]로 숨겨 여유 공간을 확보할 수 있습니다. 이미 등록된 매물은 평생 무료로 조회 및 수정이 가능합니다.
🏢 5. 아파트 & 빌라 스마트 계층형 서랍 관리
🔹 대단지 아파트 (같은 지번에 여러 동과 호수가 있을 때)
같은 지번에 101동, 102동 등 여러 동이 있다면 매물 등록 시 [건물 동]란에 101동을 입력하세요.
지번 아래에 동별 서랍 헤더(🏢 101동)가 분리되어, 101동 공동현관 비밀번호와 102동 공동비번이 서로 섞이지 않고 따로 보존됩니다.
🔹 일반 빌라 / 다가구 / 단독 건물
동 구분이 없는 일반 빌라는 [건물 동]을 비워두세요. 시스템이 알아서 단일 건물 카드로 묶어줍니다.
한 건물에 나온 201호, 302호가 하나의 건물 카드 안에 쏙 모이고, 공동현관 비밀번호는 건물 전체에 1번만 입력하면 모든 호수가 자동 공유합니다.
🔑 공동현관 비밀번호 원터치 즉시 수정

🗺️ 주소 터치 시 네이버 지도 1초 연결

3단계: 기적처럼 0.1초 만에 모든 매물과 비밀번호 복원 완료!
암호가 확인되면 이전에 기록해 두신 모든 지번, 도어락 비밀번호, 세입자 연락처, 쇼잉 장바구니 메모가 100% 원상복구됩니다.

📶 4. 지하 1층 상가·엘리베이터 음영지역 무중단 (오프라인 퍼스트)
